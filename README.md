## ✨ المميزات الرئيسية للمنصة

1. **📊 منهجية المراحل وخطة التعلم (A1 - C2):**
   - **A1 (مبتدئ - أول 1,000 كلمة):** الأساسيات وتغطية 75% من المحادثات اليومية.
   - **A2 (مبتدئ متقدم - 1,500 كلمة):** السفر، التسوق والتعبير عن الماضي والمستقبل.
   - **B1 (متوسط - 2,500 كلمة):** العمل والاتصالات ومناقشة الآراء والمشاعر.
   - **B2 (فوق المتوسط - 2,500 كلمة):** التحليل، الأعمال والتقنية.
   - **C1/C2 (إتقان واحتراف - 2,500 كلمة):** البلاغة، التخصصات ومفردات الشارع المتقدمة.

2. **🗂️ بطاقات استذكار ذكية (3D Flashcards):**
   - تصميم ثلاثي الأبعاد تفاعلي يقلب البطاقة لمعرفة الترجمة، نوع الكلمة، والمثال.
   - نطق صوتي أصلي للكلمة البرتغالية والمثال العملي باللكنة البرازيلية الرسمية (`pt-BR`).
   - تتبع الكلمات الصعبة والسهلة، ونظام مكافآت ونقاط خبرة (XP) ومتابعة الأيام (Streak).

3. **🎮 ساحة التحديات والاختبارات (Quiz Arena):**
   - أسئلة اختيار من متعدد سريعة وممتعة تثبت الحفظ في الذاكرة طويلة المدى مع عداد فوري للنقاط.

4. **📖 القاموس الشامل (10,000 كلمة مع بحث فوري):**
   - بحث فوري وسريع بالكلمة البرتغالية، أو الترجمة العربية، أو النطق الصوتي التقريبي.
   - فلترة ذكية وسريعة حسب مستويات CEFR.
   - جداول منظمة تتضمن نوع الكلمة، أمثلة تطبيقية مع ترجمتها، وأزرار استماع فوري.

5. **📝 تصريف الأفعال الأساسية والشاذة (Verbs):**
   - جدول تفاعلي لأهم الأفعال الشاذة والمنتظمة وتصريفاتها في الحاضر والماضي والمستقبل واسم الفاعل (Gerúndio).

6. **💬 العامية البرازيلية (Gírias):**
   - أهم التعبيرات الشعبية والمصطلحات الدارجة في الشارع البرازيلي لشرح معانيها وسياق استخدامها.

7. **🤖 المعلم الذكي (Gemini AI Tutor):**
   - مدعوم بالذكاء الاصطناعي من Google Gemini للدردشة والمحادثة التفاعلية وتصحيح الجمل بالبرتغالية في أي وقت.

8. **⚡ عمل كامل بدون إنترنت (Offline-First):**
   - بعد التحميل الأول، يتم تخزين الكلمات والتقدم تلقائياً داخل المتصفح عبر `IndexedDB` ليعمل التطبيق في أي مكان بدون اتصال بالإنترنت.

## 🌐 كيفية تفعيل الموقع على GitHub Pages مجاناً

المشروع مصمم ليعمل كصفحة ثابتة (Static Web App) دون الحاجة لأي خادم خلفي أو أدوات بناء:

1. ادخل إلى مستودع المشروع على GitHub: `https://github.com/smo5ke/falabrasil`
2. اضغط على تبويب **Settings** (الإعدادات).
3. من القائمة الجانبية اليسرى، اختر **Pages**.
4. تحت قسم **Build and deployment**:
   - Source: اختر **Deploy from a branch**.
   - Branch: اختر فرع **main** وتأكد من أن المجلد هو **/(root)**.
5. اضغط على زر **Save**.
6. في غضون دقيقة إلى دقيقتين، سيظهر لك الرابط الحي لموقعك:
   ```text
   https://smo5ke.github.io/falabrasil/
   ```

## 💻 التشغيل المحلي (Local Running)

يمكنك تشغيل الموقع محلياً على جهازك بأي من الطرق التالية:

### الطريقة 1: باستخدام Python
```bash
python -m http.server 8000
```
ثم افتح المتصفح على: `http://localhost:8000`

### الطريقة 2: باستخدام Node.js (npx serve)
```bash
npx serve .
```

## 🛠️ التقنيات المستخدمة

- **Tailwind CSS:** لتصميم الواجهات العصرية المتجاوبة.
- **Alpine.js:** لإدارة الحالة والتفاعل الخفيف وفائق السرعة.
- **SheetJS (xlsx):** لمعالجة واستيراد ملفات الإكسل الضخمة محلياً داخل المتصفح.
- **LocalForage:** للتخزين غير المتزامن وفائق السرعة للبيانات في `IndexedDB`.
- **Web Speech API:** لنطق الكلمات والأمثلة باللكنة البرازيلية الأصلية.
- **Google Gemini API:** لمعلم الذكاء الاصطناعي والمحادثة الفورية.
